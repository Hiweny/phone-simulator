# 📱 手机模拟器 - Standalone V4.0

完全独立的手机模拟器网站，脱离酒馆平台，自包含所有功能。

## ✨ 功能特性

- **聊天模拟**：QQ 和微信风格的聊天界面，支持多角色对话
- **免费聊天 API**：默认使用免费公益 API（`https://free-api.cnmwx.com/v1/completions`）
- **OpenAI 兼容**：支持切换为任意 OpenAI 兼容格式的 API
- **AI 生图**：内建生图功能，默认使用 `step-image-edit-2` 模型
- **生图 API 可切换**：支持配置任意 OpenAI 兼容的生图 API
- **完整设置面板**：所有 API 配置均在手机设置中可视化完成
- **预设系统**：内建多套对话预设（破限、防重复、防抢话等）
- **无需 RP-Hub**：完全独立运行，不依赖任何外部平台

## 🚀 快速开始

1. 下载 `index.html`
2. 用浏览器打开即可使用
3. 点击手机屏幕上的"开机"按钮
4. 在设置中配置你的 API（默认已配置免费聊天和生图 API）

## ⚙️ 设置说明

### 聊天 API
- **默认**：免费公益 API，无需 Key
- **切换**：在设置中填入 OpenAI 兼容的 API 地址和 Key 即可

### 生图 API
- **默认**：`step-image-edit-2` 模型
- **切换**：在设置中修改生图 API 地址、Key 和模型名

## 📦 部署

单文件 HTML，可直接部署到：
- GitHub Pages
- Vercel
- Netlify
- 任何静态文件服务器

## 🔧 技术细节

- 纯前端实现，无后端依赖
- 所有配置保存在浏览器 localStorage
- 支持流式文本（SSE）响应
- 生图支持 OpenAI 兼容格式
