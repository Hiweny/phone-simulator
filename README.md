# 手机模拟器 - Phone Simulator

一个完全独立的手机社交模拟器，脱离酒馆（SillyTavern）平台运行。

## 功能

- **QQ/微信聊天**：拟真聊天界面，支持群聊、私聊，AI主动发消息
- **论坛**：成人论坛，AI自动发帖回帖
- **直播**：直播互动，虚拟货币系统
- **真实时间与天气**：自动获取真实天气数据
- **联系人系统**：创建自定义人物，配置性格、外貌等
- **关系感知**：AI根据好感度、关系阶段自然互动
- **表情包和语音**：AI自动发送表情和语音消息

## 使用方法

1. 下载 `index.html`
2. 用浏览器打开即可
3. 首次启动会引导你设置玩家身份
4. 在设置中可配置 API

## API 配置

### 默认免费 API
内置免费公益 API，开箱即用，无需任何配置。

### OpenAI 兼容 API
在设置中切换到"OpenAI 兼容 API"模式，填入你的 API 地址和 Key 即可。

支持所有 OpenAI 兼容格式的 API。

## 部署

直接部署到任何静态网站托管服务：
- GitHub Pages
- Vercel / Netlify / Cloudflare Pages
- 任何 HTTP 服务器

## 技术说明

- 纯前端单文件 HTML 应用
- 所有数据存储在浏览器 localStorage
- 天气数据使用 Open-Meteo 免费 API
- 不依赖任何后端服务
