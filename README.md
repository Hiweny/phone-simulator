# 手机模拟器 - Phone Simulator

一个完全独立的手机社交模拟器，脱离酒馆（SillyTavern）平台运行。

## 功能

- QQ/微信聊天：拟真聊天界面，支持群聊、私聊，AI主动发消息
- 论坛：成人论坛，AI自动发帖回帖
- 直播：直播互动，虚拟货币系统
- 真实时间与天气：自动获取真实天气数据
- 联系人系统：创建自定义人物，配置性格、外貌等
- 关系感知：AI根据好感度、关系阶段自然互动
- 表情包和语音：AI自动发送表情和语音消息

## API 配置

### 默认免费API
内置免费公益API，开箱即用，无需任何配置。

### OpenAI 兼容API
在设置中切换到OpenAI兼容API模式，填入你的API地址和Key即可使用其他供应商。

## 使用方法

1. 下载 index.html
2. 用浏览器打开即可
3. 首次启动会引导你设置玩家身份
4. 在设置中可配置API

## 部署

直接部署到任何静态网站托管服务：GitHub Pages、Vercel、Netlify、Cloudflare Pages等。

## 技术说明

- 纯前端单文件HTML应用
- 所有数据存储在浏览器localStorage
- 不依赖任何后端服务（除AI API外）
- 天气数据使用Open-Meteo免费API

## 来源

基于酒馆角色卡提取并独立化。
